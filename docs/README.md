# Idea2Image Documentation

Welcome to the Idea2Image documentation. This folder contains in-depth information about the project: architecture, setup, usage, developer guidance, testing, and deployment.

Jump to:

- `architecture.md` — Project components and data flow
- `setup.md` — Local development setup, virtualenv and Windows helper usage
- `usage.md` — How to run and use the Gradio UI and CLI helper
- `developer.md` — Code structure, contribution guidelines and style
- `testing.md` — Running tests and coverage
- `deployment.md` — Docker-based deployment and production recommendations

If you are new to the repository, start with `setup.md` then `usage.md`.
